# Set-SDPSite

## SYNOPSIS

 [[-City] <String>] [[-State] <String>] [[-Country] <String>] [[-RegionId] <String>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
