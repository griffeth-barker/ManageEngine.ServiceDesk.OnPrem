# New-SDPOrgUser

## SYNOPSIS

 [[-LoginName] <String>] [[-Password] <String>] [[-EmailId] <String>] [[-Phone] <String>] [[-Mobile] <String>]
 [[-JobTitle] <String>] [[-EmployeeId] <String>] [-IsVipUser] [[-DepartmentId] <String>]
