# Remove-SDPRequest

## SYNOPSIS
Deletes a request from ServiceDesk Plus.

## SYNTAX

```
Remove-SDPRequest [-Id] <String> [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```
