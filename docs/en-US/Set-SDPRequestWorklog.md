# Set-SDPRequestWorklog

## SYNOPSIS
Updates a worklog entry on a ServiceDesk Plus request.

## SYNTAX

```
Set-SDPRequestWorklog [-RequestId] <String> [-Id] <String> [[-Description] <String>] [[-OwnerName] <String>]
 [[-TimeSpentHours] <String>] [[-TimeSpentMinutes] <String>] [-MarkFirstResponse]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```
