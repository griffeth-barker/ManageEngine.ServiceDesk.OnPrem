# Add-SDPProblemTaskCommentReply

## SYNOPSIS
Replies to a comment on a task for a ServiceDesk Plus problem.

## SYNTAX

```
Add-SDPProblemTaskCommentReply [-ProblemId] <String> [-TaskId] <String> [-CommentId] <String>
 [-Description] <String> [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```
